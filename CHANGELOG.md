# Changelog

All notable changes are recorded here, following
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
This project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html);
the 0.x certificate schema and Python API remain experimental.

## [Unreleased]

### Changed

- Update the separate finite-motion study to hash-locked mpmath 1.4.1 and
  record a fresh study source manifest. Both packaged replays preserve all
  numerical reference rows and pass the numerical and artifact controls.

- Update the optional prototype to NumPy 2.4.6 and SciPy 1.17.1, align its
  runtime checks and dependency documentation, and record a fresh source
  manifest. Reproduce and inspect two matching packaged synthetic runs in
  the updated numerical environment.

- Extend the offline explorer with a guided geometry, nominal Gaussian snapshot
  and certificate presentation. Display the `long-exposure-v1` exact-geometry
  result alongside a selectable original `verify` view, keeping each view's
  intervals, threshold, sufficient count and assumptions together. Check both
  display records against freshly reproduced installed-package certificates.
  The seeded floating-point snapshots are magnified illustrations of one-time
  covariance; they do not certify the classifier, supply experimental evidence
  or change the scientific runtime contract.

- Shorten the README around the conditional 63-point result and reproduction.
  State the tiny RMS motion scale and existence-result scope prominently in
  the README and proof write-up. Keep the calibrated iid channel separate,
  retain classical homometry and diffuse-scattering context, and label review
  materials as internal cross-checks. Replace Lean declaration counts in the
  overview with substantive statements while preserving the detailed mappings,
  proof dependencies and research provenance disclosure.

- Use standard requirements filenames so dependency monitors can discover the
  development and optional prototype pins. Updates still require explicit
  source-manifest review and fresh artifact verification.

### Added

- A separate finite-motion numerical study with a hash-locked multiprecision
  environment, source manifest, asserted numerical cross-checks and two
  packaged replays on Windows and Linux. The selected strength grid misses
  its normal-approximation window target; independent site disorder greatly
  increases the estimated count. These numerical records do not extend the
  exact-arithmetic certificate or establish a finite-sample guarantee.

- An optional reviewer kit with SageMath nine-point moment reconstruction,
  a separate Arb calculation for one calibrated-iid 63-point channel, and
  explicit analytic dependencies and review boundaries. The `reviewer-kit`
  task checks saved witnesses and mutation controls from the built source
  archive; `release` and CI run that bounded task. Fresh Sage/Arb calculation
  commands use separate optional environments. The certificate runtime is
  unchanged. A maintainer-approved research provenance statement describes
  the substantial AI assistance and the limits of the automated checks.

- Four optional applied-Gaussian formal modules: seven physical-parameter
  statements, five integer-charge histogram statements and forty-nine
  covariance statements across two files. The analytic project now contains
  101 proved declarations in nine files. The two literal nine-point covariances
  have exact threshold, Gram, centered-inverse, PSD, trace and zero-COM proofs.
  Executable histogram/polynomial identification, dynamics and the full
  classifier remain separate. Package APIs, runtime manifests and numerical
  outputs are unchanged.

- An optional arbitrary-natural-moment Gaussian intensity formula. Nine
  proved declarations and two charge/weight definitions import the unchanged
  first-intensity module; that revision brought the analytic project to
  forty proved declarations in five files. Ordered tuple multiplicities, full PSD
  covariance, order zero and genuine finite-measure integrability are explicit.
  Graph covariance, executable histogram/polynomial identification, temporal
  dynamics and the complete classifier remain separate. Package APIs,
  runtime manifests and numerical outputs are unchanged.

- An optional generic Gaussian first-intensity-moment proof with explicit
  full PSD covariance and proved integrability. Its thirteen declarations
  include three Gaussian phase prerequisites; the four-file analytic project
  at that revision had thirty-one declarations. Concrete graph covariance,
  executable polynomial identification, temporal dynamics and the complete
  scientific theorem remain separate.
  Package APIs, runtime manifests and numerical outputs are unchanged.
- A separate phase-permutation proof and standalone exact checker for a
  complete-graph indistinguishability example. The source-archive checker
  is replayed by the normal verification task. Existing package APIs,
  mathematical source manifest and certificate outputs are unchanged.
- A separate fixed nine-point moment certificate and `small-pair` command.
  Exact witnesses establish equal leading intensity-process laws, distinct
  nonlinear laws at every shared finite positive strength, individual
  mean/skewness crossings and a local calibrated projection gap with independently
  uncertain fixed strengths. All evaluated unresolved bands remain visible.
  This construction has no detector channel or finite-count guarantee.
- Five optional Lean polynomial statements with a portable fresh mapping of
  every coefficient in the nine-point noncoincidence argument. Identifying
  the complete nine-point moment polynomials with the modeled intensity and
  proving the full scientific theorem remain outside Lean.

- A research roadmap distinguishing existing imaging methods, open mathematical
  questions, statistical targets and the calibration required before hardware
  development. Potential applications are not presented as achieved results.
- An additive `count` command and fresh API with explicit versioned profiles.
  `short-exposure-v1` keeps the 10⁻⁵ exposure cap; `long-exposure-v1`
  permits 0.001 for exact geometry and 0.01 for position uncertainty.
  Both recompute complete nonlinear shape-error allocations, thresholds
  and sufficient counts. All three earlier commands preserve their contracts.
- Signed kernel derivative/remainder bounds, a rank-two majorization bound,
  all 512 exposure cells and independent class-wise nuisance-propagated
  skewness unions for the long profile. The unresolved exact-geometry
  cap 0.01 and separately evaluated position cap 0.001 remain visible.
- Four optional real-variable sensitivity statements in the pinned analytic
  Lean project, alongside its nine unchanged variance declarations.
  These bounded statements do not formalize the full probabilistic theorem.
- An explicit profile decision record and FAQ separating sufficient counts,
  exposure domains, fixed settings and physical calibration requirements.

- An additive `exposure-count` command and API with a linear exposure-moment
  bound and Gaussian parity transfer. Both scenarios permit normalized exposure
  up to 10⁻⁵, with freshly recomputed sufficient counts and classifiers.
  The original commands and parameter contracts remain available.
- An optional `coordinate-count` command and API that recompute the full
  core and a separate exact coordinate-tolerance witness. Sufficient counts
  fall to 26,814,048,499,063,502 and 26,808,243,624,540,316 for the two
  scenarios, with all model assumptions and the classifier unchanged.

- A portable, standard-library certificate for one fixed chain of geometry,
  Gaussian motion, covariance uncertainty, exposure, frequency error and
  dependent photon-count discrimination.
- Exact rational inputs, source integrity manifest, installed-artifact tests,
  proof documentation and explicit limitations.
- A new release implementation and fresh verification workflow. Historical
  execution records are not included or represented as this release.
- A separately verified position-uncertainty scenario with its own joint
  frequency domain and finite-window count.
- An offline interactive geometry and certificate demo, checked against fresh
  installed-package output.
- Six finite arithmetic Lean checkpoints and six symbolic falling-factorial
  identities, with explicit limits on their formal coverage.
- A separate pinned Lean/mathlib project for general standard-deviation
  continuity and variance enclosures, with explicit finite-moment assumptions
  and limits on its connection to the full theorem.
- An optional synthetic instrument with eight scenarios per class, complete
  simulated motion records, a saved-output inspector and separate numerical
  dependencies. It does not claim physical validation or classifier performance.
